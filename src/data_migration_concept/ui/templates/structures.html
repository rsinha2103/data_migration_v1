Define a target structure

Pick one way in. You can add more structures later, and update one from a newer template.

A. Upload a template file

SAP Migration Cockpit template (.xml or the .zip of CSV files), or your own .xlsx / .csv list of fields. Several structures in one file are fine - you choose which to create.

No template yet? Download a blank one to fill in: Excel · CSV

B. Type or paste the fields

One field per line: name, then optionally description, type, length, mandatory (X). You can paste straight from Excel.

C. Copy the source columns

Quick start when there is no target template: every source column becomes a target field that moves itself. Rename and adjust afterwards.
